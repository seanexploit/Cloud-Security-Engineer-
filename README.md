# Cloud-Security-Engineer-

# AWS Cloud Security Engineer Project Documentation

## Project Overview

This project focused on implementing and validating cloud security controls across AWS environments. The objective was to gain practical experience securing identities, networks, workloads, monitoring infrastructure, incident response processes, and security automation.

---

# Phase 1 – IAM Hardening

## Objective

Strengthen AWS identity security and reduce the risk of unauthorized access.

## Activities Performed

* Reviewed IAM users, groups, and permissions.
* Applied least-privilege access principles.
* Evaluated administrative permissions.
* Studied account security controls and access management.

## Skills Developed

* Identity and Access Management (IAM)
* Least Privilege Design
* Access Control Review
* Security Governance

## Security Impact

Proper IAM configuration reduces the likelihood of account compromise and privilege escalation attacks.

---

# Phase 2 – Network Security

## Objective

Design secure cloud network boundaries.

## Activities Performed

* Studied VPC architecture.
* Reviewed subnet segmentation concepts.
* Evaluated inbound and outbound traffic controls.
* Analyzed security groups and network access restrictions.

## Skills Developed

* AWS VPC Security
* Network Segmentation
* Security Group Management
* Zero Trust Principles

## Security Impact

Network segmentation limits attacker movement and reduces the blast radius of security incidents.

---

# Phase 3 – Compute and Storage Security

## Objective

Protect cloud workloads and stored data.

## Activities Performed

* Reviewed EC2 security concepts.

## Skills Developed

Securing workloads and data prevents unauthorized access and information disclosure.
